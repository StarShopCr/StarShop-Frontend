# crowdfunding_collective JS

JS library for interacting with [Soroban](https://soroban.stellar.org/) smart contract `crowdfunding_collective` via Soroban RPC.

This library was automatically generated by Soroban CLI using a command similar to:

```bash
stellar contract bindings typescript \
  --network testnet \
  --id <contract_address> \
  --output-dir ./packages/crowdfunding_collective \
  --overwrite
```

## Usage

```typescript
import { Client, networks } from "crowdfunding_collective";

const client = new Client({
  ...networks.testnet,
  rpcUrl: "https://soroban-testnet.stellar.org",
});

// Create a crowdfunding product
const productId = await client.create_product({
  creator: "G...",
  name: "My Product",
  description: "A crowdfunding campaign",
  funding_goal: BigInt(10000),
  deadline: BigInt(Date.now() + 30 * 24 * 60 * 60 * 1000),
  reward_tiers: [],
  milestones: [],
});

// Contribute to a product
await client.contribute({
  contributor: "G...",
  product_id: 1,
  amount: BigInt(500),
});
```
